GOOD QUESTIONS

Before you press play.

Is CatsMC accepting customers now?

Not yet. This is a static website template. You must set up actual server hosting, customer support, and billing before accepting orders.

Does Cloudflare Pages run Minecraft servers?

No. Pages hosts the website's static files. Run Minecraft servers on a separate game server host or suitable machine.

Which server software can I offer?

Depending on Minecraft version and compatibility, you can offer established projects such as Paper, Fabric, Forge, or vanilla server software. Check each project's official documentation and licensing.

Do the prices on this page work?

No. They're example prices for the design only. Replace them with real plans after you calculate hardware, bandwidth, backups, support, and other costs.
